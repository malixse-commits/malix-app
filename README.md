# malix-app

En enkel första version av Malix-appen för vardagsplanering, återhämtning, mat, träning och reflektion.

## Första versionen innehåller

- Daglig översikt
- Matlogg
- Träning och rörelse
- Grön, gul och röd tid
- Sömn och stress
- Kalender
- Städa i fyrkanter
- Min inre kompass / reflektion
- Lokal lagring i webbläsaren

## Viktigt

Detta är en första prototyp. Uppgifterna sparas endast lokalt i användarens webbläsare och synkroniseras inte mellan enheter.
